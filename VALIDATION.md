# Проверки версии 1.0

## Выполнено

- Нативное измерительное ядро собрано GCC 14.2 с `-O3 -Wall -Wextra -Werror`
  и выполнено в Linux x86_64.
- Проверены размеры буферов, строго возрастающий диапазон, ошибочные настройки,
  чтение, запись, исполнение NOP-кода, медиана/границы результатов, повторное
  использование исполняемой памяти и отмена из другого потока.
- Отдельный запуск с AddressSanitizer и UndefinedBehaviorSanitizer завершился
  без ошибок; проверка утечек включена.
- CLI дал 99 реальных измерений для трёх операций в диапазоне 4 KiB — 1 MiB.
  Проверены конечность скоростей, количество точек и порядок min ≤ median ≤ max.
- Дополнительно выполнены все 57 точек теста кода до границы 64 MiB включительно.
- Проверены некорректные аргументы CLI, `--help`, синтаксис скриптов и plist.
- Ядро ARM64 и полный интерфейс Objective-C/AppKit скомпилированы и слинкованы
  для macOS 12+ с SDK macOS 14.5, Zig 0.13 / Clang, без ошибок и предупреждений
  при `-Wall -Wextra -Werror`.
- Получен настоящий Mach-O ARM64 executable. Зависимости — только системные
  библиотеки и фреймворки macOS. Приложение не является Linux-файлом с расширением `.app`.
- Bundle подписан ad-hoc через Apple Codesign (rcodesign) 0.29, с Hardened Runtime
  и единственным entitlement `com.apple.security.cs.allow-jit`.
- Отдельным скриптом проверены SHA-256 страниц Mach-O, специальные слоты подписи,
  хэши Info.plist/CodeResources и ресурсы bundle. ZIP проверен после упаковки.

## Не выполнено

- Запуск окна AppKit на настоящем Mac.
- Выполнение NEON/JIT на Apple M5 и проверка поведения именно macOS Tahoe 26.6.2.
- Проверка готового bundle утилитой Apple `codesign` и прохождение Gatekeeper.
- Подпись Developer ID и нотариализация Apple.

Среда разработки — Linux x86_64. Кросс-компиляция и проверка хэшей не заменяют
запуск на macOS. Linux-измерения не являются результатами M5 и не включены в
приложение как готовые данные.

У `rcodesign verify` 0.29 для этой ad-hoc подписи возникает ошибка разбора
пустого CMS (у ad-hoc подписи нет подписи сертификатом). Поэтому успешная
проверка этим инструментом не заявляется; содержимое подписи проверено отдельно.
Локальный `build.sh` использует штатный Apple `codesign`, проверяет подпись и
выполняет тесты ядра на самом Mac перед открытием приложения.

## Первый запуск на Mac

1. Открыть приложение, убедиться, что CPU и RAM определились.
2. Выполнить Cache Speed / 64 MiB / Быстрый; ожидать измеренные жёлтую и зелёную линии.
3. Проверить Read RAM и Write RAM; остановить один прогон кнопкой «Стоп».
4. Экспортировать CSV, проверить наличие измерений и отметки частичного прогона.
5. Если готовый bundle не запускается, пересобрать через `build.sh` (инструкция
   в README). Для диагностики сохранить текст ошибки или отчёт о сбое приложения.
